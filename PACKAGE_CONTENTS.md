# Package contents

The ZIP includes source code, tests, exact dependency pins, documentation, manuscript draft, all four completed study outputs, source snapshots, trusted locally trained model bundles, probabilities, per-flow decisions, result figures and verification records.

It excludes raw and prepared datasets, Python environments, caches and generated package metadata. In the original local folder, the downloaded archive and prepared cohorts remain under data/. To reproduce after moving the ZIP, use the documented download/prepare commands.

The corrected studies are development follow-ups on reused benchmark partitions; the retained pilot studies show their diagnostic predecessors. They must not be pooled as independent datasets or independent confirmation.

PACKAGE_MANIFEST.json records SHA-256 fingerprints of all included files except the manifest itself. The GitHub target is https://github.com/gokulruthrapathy/context-aware-adaptive-firewall. No journal submission has been performed.
